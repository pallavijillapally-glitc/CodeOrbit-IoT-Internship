# CodeOrbit-IoT-Internship
IoT internship projects and tasks completed for CodeOrbit Tech.
Task 2: Sensor Data Simulation Project

Project Name: IoT Temperature Monitoring System

Description:
This project simulates temperature sensor readings using Python. It generates 10 random readings, detects high temperatures above 35°C, saves the readings in a CSV file, and generates a temperature graph using Matplotlib.

Tools Used: Python, CSV, Matplotlib

Files:

- "temperature_monitor2.py" – Python source code
- "temperature_data.csv" – Sensor readings
- "temperature_graph.png" – Temperature graph

Result: Successfully generated simulated temperature data, detected high-temperature conditions, saved the data, and displayed the graph.
