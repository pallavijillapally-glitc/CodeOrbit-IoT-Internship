# CodeOrbit-IoT-Internship




IoT Internship Projects and Tasks – CodeOrbit Tech

This repository contains the projects and tasks completed as part of the Internet of Things (IoT) internship at CodeOrbit Tech.

Task 1: IoT Concepts and Architecture Study

Objective

To understand the basic architecture of an Internet of Things (IoT) system and the role of its major components.

Key Concepts

- Sensors: Collect data from the environment, such as temperature, humidity, and motion.
- Connectivity: Transfers data through Wi-Fi, Bluetooth, or other communication technologies.
- Cloud Platform: Stores and processes sensor data.
- Application Layer: Displays information to users through dashboards or mobile applications.

IoT Architecture

Sensors → Connectivity → Cloud/Data Processing → Application/Dashboard

Outcome

Learned the basic IoT architecture, its layers, and how these components work together in real-world applications.

Deliverable: IoT Concepts and Architecture Study PDF.

Task 2: Sensor Data Simulation Project

Project Title

IoT Temperature Monitoring System

Objective

To simulate temperature sensor readings using Python, identify high-temperature conditions, and visualize the readings.

Technologies Used

- Python 3
- Matplotlib
- CSV module
- Random module

Implementation

- Generated simulated temperature readings using Python.
- Compared the readings against an alert threshold of 35°C.
- Displayed normal and high-temperature status messages.
- Saved the temperature readings in a CSV file.
- Created a line graph to visualize temperature changes.

Output Files

- "temperature_monitor.py"
- "temperature_monitor2.py"
- "temperature_data.csv"
- "temperature_graph.png"

Outcome

Successfully simulated temperature data, detected high-temperature conditions, stored readings in a CSV file, and generated a temperature trend graph.

Task 3: Simple IoT Dashboard

Project Title

IoT Temperature Dashboard

Objective

To design a simple dashboard that displays simulated sensor readings, temperature trends, and alerts for monitoring temperature conditions.

Technologies Used

- Python 3
- Tkinter
- Matplotlib
- Random module

Features

- Displays the current simulated temperature.
- Shows a high-temperature alert when the reading exceeds 35°C.
- Displays normal status when the temperature is 35°C or below.
- Visualizes temperature readings using a line graph.
- Shows the latest 10 temperature readings.
- Includes a Refresh Dashboard button to generate a new simulated reading.

How to Run

1. Install Python 3.

2. Install Matplotlib using:
   
   "py -m pip install matplotlib"

3. Open "iot_dashboard.py" in Python IDLE.

4. Press F5 to run the program.

5. Click Refresh Dashboard to generate a new temperature reading.

Output File

- "iot_dashboard.py"
- "iot_dashboard_screenshot.png" (dashboard screenshot, if uploaded)

Outcome

Successfully developed a basic interactive dashboard for simulated temperature monitoring, including a live-style temperature display, trend graph, and threshold-based alerts.
